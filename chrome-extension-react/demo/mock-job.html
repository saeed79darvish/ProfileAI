Senior Frontend Engineer

📍 San Francisco, CA (Hybrid) 💼 Full-time 💰 $165,000 – $210,000 Engineering

About the Role

Northwind Robotics is building the next generation of warehouse automation software. We're looking for a Senior Frontend Engineer to lead the development of our customer-facing control dashboards. You'll work closely with product, design, and backend teams to ship scalable, production-grade interfaces used by operations teams around the world.

What you'll do

  • Build and maintain complex, responsive web applications using React and TypeScript.
  • Architect reusable component libraries and contribute to our internal design system.
  • Collaborate cross-functionally with design and backend engineers to deliver polished features.
  • Optimize application performance, accessibility, and rendering for large real-time datasets.
  • Mentor junior engineers and help define frontend best practices and code standards.

What we're looking for

  • 5+ years of professional experience building production web applications.
  • Deep expertise in React, TypeScript, and modern JavaScript (ES6+).
  • Strong understanding of HTML, CSS, and responsive, accessible UI development.
  • Experience with state management, REST/GraphQL APIs, and component testing.
  • Familiarity with Node.js and modern build tooling (Vite, Webpack).
  • Excellent communication and cross-team collaboration skills.

Nice to have

  • Experience with Next.js, WebSockets, or real-time data visualization (D3.js).
  • Background working on design systems or component libraries at scale.
  • Exposure to CI/CD pipelines and frontend observability tooling.
